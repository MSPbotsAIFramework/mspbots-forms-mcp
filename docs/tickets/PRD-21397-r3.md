## Rework triage

The description was rewritten on 2026-11-17 after Micus answered Mandy's three questions "yes" (comment 1600390000098604): decisions (a) MCP tools are v1 and the Forms-page buttons are a separate card (PRD-22280), (b) "workspace admins only" means the connector allowlist, (c) data-source fields import unbound and are listed in the report. Done-when was rewritten from 5 items to 7 (new numbering below), and a new item 7 asks that the connector deployment checklist and the test tenant allowlist say admin-only. Code that is already built and not touched by this round: export, import, sanitize, title override, uncapped export, refusal of truncated files (src/mspbots_forms_mcp/tools/transfer.py, _transfer_sanitize.py, _json.py at f11fc12).

One line: A form built and tested in one tenant can be copied into another tenant's Forms exactly, without hand-rebuilding it, by exporting it to a file with mspbots_forms_form_export and importing that file with mspbots_forms_form_import.

New acceptance criterion (this round):

- **AC10** (access control, decision b): Given the MSPbots Forms connector, Then the documentation (README and the docs.mspbots.ai connector page) tells the deploying admin to allow mspbots_forms_form_export and mspbots_forms_form_import for the workspace admin role only and deny them to other roles, and states that the MCP server itself performs no role check because it receives no user role. In the test tenant the per-tool allowlist is configured that way.

Scope boundary (from the ticket): no Export/Import buttons on the Forms page (PRD-22280), no role check inside the server, no platform role pass-through.

Open questions: none blocking. Assumption: the test-tenant allowlist (TC19) is set by a tenant admin in the platform UI; the pipeline cannot do it. The cross-tenant fixture (an agent with the Forms connector in tenant 2qmxyw) is not provided yet (comment 1600390000098604); it is a test-time dependency for TC2/TC3, not a design gap.

wiki: ProductDocs not needed for this change (no UI change); the connector page https://docs.mspbots.ai/connectors/mspbots-forms/ was read on 2026-11-17 and has no allowlist or admin-only text, only a sentence that agents can copy a form between tenants.
